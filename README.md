# Trabajo Práctico: Colaboración y Flujo de Trabajo en GitHub

## 📌 Descripción
Este proyecto tiene como objetivo representar un registro web, con su respectivo login y register de una cuenta. 

## 🛠️ Tecnologías utilizadas
- **HTML**
- **CSS**
- **JavaScript**

## 🚀 Instrucciones de ejecución

Para clonar y ejecutar el proyecto de manera local:

1. **Abrir Visual Studio Code en una ventana nueva**  
   Inicia VS Code para trabajar en un entorno limpio.

2. **Clonar el repositorio desde GitHub**  
   Ejecuta en la terminal integrada de VS Code:  
   git clone https://github.com/escfogarmartin-rgb/Trabajo-en-GitHub.git
3. **Luego de clonar presiona enter y escribe**
   cd Trabajo-en-GitHub
4. **Abrir la carpeta del repositorio en visual**
5. **Si se encuentran todos los archivos darle click al index.html y abrirlo en la web**
